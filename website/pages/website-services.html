FAQ

School websites: common questions

How much does a school website cost?

It depends on the number of pages and features you need. After a short call we share a fixed quote, so there are no surprises later.

Do we need to use the Smart Gurukul app?

No. Any school can ask us for a website. If you do use the app, we link your website to it.

Can the website be in Hindi?

Yes. We can build it in Hindi, English or both, with a language switch.

Can we update the website ourselves?

Yes. We can set it up so your staff can post notices and photos, or we can make updates for you on a maintenance plan.

We already have a website and domain. Can you work with them?

Yes. We can redesign your existing website and keep your current domain.
